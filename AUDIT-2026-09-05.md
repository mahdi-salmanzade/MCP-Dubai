# MCP-Dubai audit - 2026-09-05

## Result and scope

Reviewed the repository as of **5 September 2026, Asia/Dubai**: runtime and shared infrastructure, all 16 business JSON packs, agent composition, selected school records, holidays, live anonymous services, dependency releases and advisories, CI/publication configuration, packaging, and documentation. The catalogue remains **120 tools, 37 features, and 19 knowledge domains**. Concrete defects and sourced changes were corrected and regression-tested.

This is a repository-wide audit with **targeted fact verification**, not a claim that every stored fee, eligibility rule, estimate, or historical assertion is current. All 16 packs received material corrections or additions; `setup_advisor` and `data_analyst` also changed. Their latest-update dates are September 5. Prior full-review dates are preserved, and `last_refresh_scope` describes each targeted update. `arabic_writer` retains April 13. Historical audit reports remain unchanged.

The project remains alpha. Local source and registry manifest are version **0.4.0**; [PyPI](https://pypi.org/project/mcp-dubai/) still publishes **0.2.0**, and the public MCP Registry search returned no matching record. No commit, tag, push, publication, deployment, or message to another person was performed.

## Correctness and resilience fixes

- **CBUAE exchange-rate parsing:** the live endpoint now returned English currency labels, which the Arabic-only mapping exposed with null names and codes. The parser now accepts either language, preserves the exact upstream label as `source_currency`, and supplies canonical bilingual names and codes. All **77 live rows** mapped uniquely after the fix. A dated HTML fixture covers this actual contract change. Offshore yuan retains the market code CNH, not a claim of a separate ISO 4217 currency. The base-rate parser also rejects successful HTTP error pages instead of extracting unrelated numbers as rates.
- **Founder planning and provenance:** projected revenue was incorrectly passed as taxable income, with a free-zone assumption. Plans now request taxable income and the required eligibility facts. An arbitrary synthesized report no longer claims every knowledge domain contributed; callers can explicitly identify referenced domains.
- **Setup and budgets:** low-budget recommendations no longer override regulated crypto activity requirements. Unknown free-zone fees are null, cannot pass a stated budget, and carry a quote-required flag. Banking recommendations expose plan fees and source scope; unknown balances cannot satisfy a budget.
- **Rent-increase boundary:** exactly 10% below the market rent now yields **0%**, following the DLD band. Adjacent band boundaries and decimal inputs have regressions. [DLD tenancy guide](https://dubailand.gov.ae/media/wzfpke5h/tenancyguideen.pdf)
- **Malformed upstream responses:** CKAN, weather, currency, OAuth expiry, Overpass tags and Makani payloads now fail predictably when required structures or finite numeric values are invalid. Currency multiplication cannot return a successful infinite amount. Existing credential redaction and hardened XML parsing remain covered.
- **VAT registration:** exact retrospective thresholds now follow the FTA's "exceeds" wording; exactly AED 375,000 does not trigger that mandatory test. Next-30-day, expense-based and nonresident cases remain explicitly separate. [FTA VAT registration](https://www.tax.gov.ae/en/taxes/Vat/vat.topics/registration.for.vat.aspx)
- **Discovery:** federal Ministry of Economy and Tourism (MOET) aliases are separated from Dubai DET/DED.
