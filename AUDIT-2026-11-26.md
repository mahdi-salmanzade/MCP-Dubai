# MCP-Dubai audit - 2026-11-26

## Result and scope

Routine audit as of **26 November 2026, Asia/Dubai**, covering changes since the 20 October audit. The strict freshness gate **failed on entry**: `funding` was 4 days past its 100-day full-review budget (tracking issue 18). It received a **full review**. Every other knowledge domain received a targeted check for news since 20 October, URLs touched by the audit were link-checked, dependencies were checked for releases and advisories, open Dependabot updates were reviewed, and anonymous upstream integrations were called live.

The catalogue remains **120 tools, 37 features and 19 knowledge domains**; version stays **0.4.0**. `funding` carries `knowledge_date` and `full_review_date` 2026-11-26. Packs with targeted changes advance only `knowledge_date`.

## Code fixes

| Area | Fix |
|---|---|
| `cbuae_base_rate` | The CBUAE endpoint, blocked by Cloudflare at earlier audits, answered again but with a new layout: a full widget with inline CSS and the rate as "Base Rate 3.900" with no percent sign. | Upstream error reasons | An httpx timeout stringifies to an empty string, so a timed-out call (seen on Overpass) returned an error with an empty `reason`. The reason now falls back to the exception type and is classified as `upstream_timeout`. One regression test added. |

FAHR announced on 13 November that the federal government holiday runs from 2 to 4 December 2026, with work resuming on 7 December. The private sector holiday is reported as 2 and 3 December only (MOHRE, via Khaleej Times, secondary). 4 December is described in the note and not added as a general holiday entry. |
| `setup_advisor` | The SaaS route's upper cost bound moves from AED 35,000 to AED 35,500, because DMCC now publishes its cheapest general package at AED 35,484. |

## Dependencies and CI

- **FastMCP:** floor moves to **3.4.11** (`fastmcp>=3.4.11,<4`). 3.4.10 fixes **GHSA-7xgj-8392-5q4r** (medium: post-transform component authorization skipped on direct calls), which pip-audit flagged in 3.4.9. 3.4.11 requires certifi 2026.10.19 or later after the eMudhra CA compromise; that floor also covers this project's own httpx calls.
- **python-dateutil removed.** It was declared but never imported. Version 4.0.0 was released on 1 November, so the dependency was dropped and the Dependabot range bump is moot.
- **Dependabot, applied on `main`:** hatchling 1.33.0 and actions/setup-python 7.1.0 (pinned SHA checked against the release tag).
- **Not applied:** the range bump to `mcp<3`. FastMCP 3.x caps mcp below 2, so the wider range would change nothing until the FastMCP 4 migration, which stays out of scope. No mcp 1.x release after 1.30.0.
- **pip-audit:** no known vulnerabilities in a clean install or in the upgraded development environment. The stale local environment had shown advisories in authlib, certifi, dnspython, joserfc and opentelemetry-api; a fresh resolve already picks fixed versions.
- Local tools moved to ruff 0.17.6, mypy 2.4.1, pytest 9.2.0 and pydantic 2.14.4 with no new findings.
