# MCP-Dubai audit - 2026-09-28

## Result and scope

Targeted refresh of the repository as of **28 September 2026, Asia/Dubai**, covering changes since the 5 September audit. Knowledge packs were re-checked against primary sources, runtime code was reviewed for correctness, and dependencies were checked for releases and advisories. The catalogue remains **120 tools, 37 features and 19 knowledge domains**; version stays **0.4.0**.

This is a targeted refresh, not a full re-verification. Changed packs carry `knowledge_date` 2026-09-28 with a rewritten `last_refresh_scope`; `full_review_date` values are preserved. `ip_trademark`, `halal` and `founder_essentials` were re-checked and needed no change, so they keep their earlier stamps.

## Correctness fixes

- **Holiday default year:** `uae_holidays` defaulted to `year=2026`, which would keep serving the 2026 calendar from 2027 on. The default now follows the current UAE date.
- **Setup-decision plans:** `analyze_setup_decision` passed industries such as `ai`, `crypto` and `education` straight to `qfzp_check` and `bank_recommendation`, which reject them. The plan now maps each value onto the closest category the downstream tool accepts.
- **Quran search:** the upstream "nothing matching" HTTP 404 now returns an empty result instead of an upstream failure that degraded service health.
- **data.dubai paging:** a page past `lastPage` is an empty page, not an error.
- **Tool discovery:** `top_k <= 0` returns no results instead of slicing from the end.
- **Salik estimate:** day names are case-insensitive ("Sunday" was billed at the weekday peak rate) and unknown days fail explicitly.
- **DUL eligibility:** bank matching uses whole tokens, so inputs such as "bank" or "e" no longer report a false integration.
- **Currency codes:** must be exactly three ASCII letters before they are placed in the request path.
